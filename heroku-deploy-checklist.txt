Heroku deployment checklist

1. Create the app:
   heroku create

2. Set required config vars:
   heroku config:set NODE_ENV=production
   heroku config:set CORS_ORIGIN=https://your-app.herokuapp.com
   heroku config:set SUPABASE_URL=...
   heroku config:set SUPABASE_ANON_KEY=...
   heroku config:set SUPABASE_SERVICE_ROLE_KEY=...
   heroku config:set SUPABASE_DOCS_BUCKET=loan-documents
   heroku config:set AGENT_WEBHOOK_SECRET=replace-with-long-random-secret

3. Set optional config vars only if you use those features:
   - DOCUMENT_AI_*
   - AI_CHAT_*
   - OCR_*
   - TWILIO_*
   - WHATSAPP_*
   - GOOGLE_TTS_*

4. Deploy:
   git push heroku main

5. Verify after deploy:
   - / loads the frontend
   - /api/health returns 200

Notes
- Do not set `API_PORT`; Heroku injects `PORT` automatically and the server already falls back to it.
- Keep `package-lock.json` committed so Heroku uses npm consistently.
- A root `Procfile` is already present, so Heroku will start the app with `npm start`.
